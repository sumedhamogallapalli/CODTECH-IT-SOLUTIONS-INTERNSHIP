# CODTECH IT SOLUTIONS — Task 4: Machine Learning - Spam Detection 📧

A Machine Learning project developed as part of my **CODTECH IT SOLUTIONS Internship** to classify SMS messages as spam or legitimate messages.

The project is implemented as a comprehensive **Jupyter Notebook** and demonstrates the complete Machine Learning workflow, from data preparation and text feature extraction to model training and performance evaluation.

---

## 📌 Project Overview

The objective of this project is to develop a predictive Machine Learning model capable of classifying SMS messages into two categories:

- **Spam**
- **Ham (Legitimate Message)**
